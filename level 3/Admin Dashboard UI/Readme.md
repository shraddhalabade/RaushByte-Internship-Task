# SLBlog Admin Dashboard

## About the Project
SLBlog Admin Dashboard is an admin interface designed to manage and monitor blog-related information from one place. I created this project to practice dashboard design, data presentation, and building a structured interface with different sections.

## Features
- Sidebar navigation
- Dashboard overview cards
- Analytics section
- Charts for data visualization
- Tables for displaying information
- Profile section
- Blog management interface
- Clean and organized layout
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js 

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

## What I Learned
While building this project, I practiced designing dashboard layouts, organizing information into cards and tables, creating navigation elements, and presenting data visually.
