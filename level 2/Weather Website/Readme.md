# Weather Website

## About the Project
This is a weather website that displays weather information for a searched city. I built this project to practice working with a weather API and displaying real-time weather data in a simple, user-friendly interface.

## Features
- Search for weather by city
- Display current temperature
- Show weather conditions
- Display humidity and wind speed
- Show feels-like temperature
- Five-day weather forecast
- Loading indicator while fetching data
- Error message for invalid searches
- Responsive layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Open-Meteo API

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Search for a city to view its weather information.

## What I Learned
While building this project, I practiced fetching data from an API, handling asynchronous JavaScript operations, displaying dynamic information, and managing loading and error states.
