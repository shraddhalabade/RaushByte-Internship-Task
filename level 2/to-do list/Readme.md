# SL / TASK MANAGER

## About the Project
SL / TASK MANAGER is a to-do list website that helps users organize their daily tasks in one place. I created this project to practice JavaScript functionality and build a simple, user-friendly interface for managing tasks.

## Features
- Add new tasks
- View the task list
- Mark tasks as completed
- Delete tasks
- Simple and user-friendly interface
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

## What I Learned
While building this project, I practiced DOM manipulation, handling user events, updating task lists dynamically, and designing a responsive user interface.
