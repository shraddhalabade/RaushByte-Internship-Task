# Login and Sign Up Page

## About the Project
This project is a simple login and sign-up website that allows users to access an account through a clean and user-friendly interface. It also includes password recovery functionality.

## Features
- User login page
- User registration page
- Forgot password page
- Form validation
- Password input fields
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or run the project using Live Server.

## What I Learned
While building this project, I practiced designing authentication forms, validating user input, organizing website pages, and improving the user experience.
