# SLDev – Web Development Landing Page

## About the Project
SLDev is a web development landing page created to showcase web development services and projects. I built this project with a simple and professional design to present services, highlight projects, and allow visitors to get in touch.

## Features
- Responsive navigation bar
- Home section with an introduction
- Web development services section
- Projects showcase
- Why Choose Me section
- Contact form
- Footer with useful information
- Responsive design for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript
- EmailJS for contact form integration

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

## What I Learned
While building this project, I practiced creating responsive layouts, designing service cards, organizing website sections, and adding functionality to the contact form.
