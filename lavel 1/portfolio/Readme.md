# Portfolio Website

## About the Project
This is my personal portfolio website, created to introduce myself, showcase my technical skills, and display the projects I have built. The website provides a simple way for visitors to learn about me and explore my work.

## Features
- Personal introduction section
- Profile image
- Technical skills section
- Projects showcase
- About me section
- Contact section
- Responsive design
- Smooth scrolling and animations

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

## What I Learned
While building this project, I practiced creating personal website layouts, working with images, designing responsive sections, and adding animations to improve the overall user experience.
